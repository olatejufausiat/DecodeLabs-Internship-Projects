# DecodeLab Data Analysis Project

## Project Overview
This project demonstrates the complete data analysis process using a single dataset.

## Project Stages

### 1. Data Cleaning
- Checked for missing values
- Removed duplicates
- Standardized data

### 2. Exploratory Data Analysis (EDA)
- Explored trends and patterns
- Identified key insights

### 3. SQL Analysis
- Queried and analyzed data using SQL
- Extracted business insights

### 4. Dashboard Development
- Built an interactive dashboard in Microsoft Excel
- Presented findings visually

## Tools Used
- Excel
- Power Pivot
- Pivot Tables
- SQL
